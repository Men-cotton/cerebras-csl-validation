# Two-port first-layer owner assignment

The trained two-layer arxiv workload retains the four original output nodes, 16 first-layer owners, every original CSR row and its reduction order. Nine frames on one 8 by 4 image compare the original and selected assignments at identical input scale and hidden-state handling. Both WEST ports send concurrently in every trial. The selector capacities in the compiled source limit the eligible assignments. The planner tests all 12,870 eight-owner subsets against the two fixed buffers.

The final restored-input pair in the official simulator read 693,440 and 72,868 words on the original ports, then 614,930 and 194,384 on the selected ports. The maximum decreased as the total increased. The collector interval from the data tag fell from 1,096,987 to 1,045,857 cycles. The physical run uses the previously registered arxiv two-port machine image and requires all nine frames, an independently reconstructed host payload for each port, complete returned hidden and final values and normal worker exit.

The raw returns are stored in `compare-owners/capture`. Run `observed(capture, plan, "hardware", True)` from this directory's `appliance.py` to replay them after verifying the pinned release.
