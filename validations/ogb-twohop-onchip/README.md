# Resident two-layer GraphSAGE with a host-echo control

Each dataset request loads one WSE-3 program, once. The first row of owners computes every first-layer dependency from original FP32 raw features and both trained projections. The second row gathers those activations at the final-layer PE, which checks every original hidden node exactly once, applies the complete second CSR and returns every output class. Both edge sets, the original node maps, raw features, trained checkpoint and cached GPU/FP64 results are pinned in each case.

Five tagged frames send original A on-chip, original A with host echo, half-A with host echo, half-A on-chip, and original A on-chip again. On echo frames the host receives all intermediate FP32 words into one buffer and sends the same buffer back. The device compares every re-entered word against its original value before using it. The physical worker records the actual initial-transfer digest and echo buffer digest after the timed interval. The echo frames retain both full hidden arrays. On-chip-only frames return the device's 32-bit hidden digest, coverage result and all logits. They carry no full intermediate tensor across the host link.

The experiment retains all first-owner raw clocks, row and edge counts, the final PE's 48-bit timing limbs, the original output node IDs and logits, and both echo tensors. Replay checks each complete returned echo against an independent FP64 first-layer calculation and the matching SDK raw words. It checks the final logits against independent two-layer FP64 for every frame and the GPU predictions for original A. Repeated outputs and the device-hidden digest are checked within the same resident execution. Each SHA-256-bound release contains both geometries, the rendered device sources and the official ELF load descriptions. The collector verifies the worker, actual system target, loaded hardware ELF, I/O mapping, every returned file, original graph and normal shutdown.

The small SDK calibration has two true arxiv output nodes, four hidden nodes and fourteen original raw inputs. It includes a complete five-frame capture of the physical worker's instrumented code on the simulator. The requested four-root datasets have their own complete numerical SDK calibration. The first frame also uploads persistent weights and final topology. The later A and half-A frames allow comparison without that initial upload. This reproduces the digest record from the original row degrees and source IDs, both trained matrices per layer, all selected raw FP32 rows, GPU hidden/logit words, and FP64 logits calculated from the whole-graph hidden tensor.
