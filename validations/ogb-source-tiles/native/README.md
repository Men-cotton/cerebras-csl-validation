# Native CSL delivery of an indexed source table

Each dataset uses the same 128 original destinations, selected at the median edge count after reverse Cuthill–McKee ordering, as the registered Tungsten source-table experiment. Six logical frames compare one source vector per edge and one per distinct original source in tiles of 128 entries. The owner list and addition order within every destination are fixed. The input uses the saved trained model's hidden features and final two weight matrices. Arxiv returns all 40 classes and products all 47. Each case pins its original checkpoint, GPU references, concrete CSL sources, SDK image and physical-geometry local compile. [Original Tungsten request](../../../requests/ogb-source-tiles/ogb-source-tiles-rcm128-p16-20261120-r001.json)

One physical compile and one run per dataset serve both distribution methods. Within one loaded native image, each of six logical frames runs twice, once by row broadcast and once by replicated rectangular unicast. The first delivery changes on successive frame pairs. Sequence tags 1 through 12 distinguish all actual device replies. Each delivery loads the weights at its first frame. Every frame records the edge/dictionary source transfers individually, including application bytes, delivered bytes, and blocking SDK call start and return times. Attribution of the H2D time uses just these intervals. The whole-frame elapsed time additionally covers array preparation, private metadata uploads, device launches and both readbacks.

The compiler receipt binds the returned archive, original source bytes, physical flags, application geometry, application and memcpy-helper ELFs, and their metadata. The worker rehashes its actual deployed application, helpers, RPC and host sources and verifies an SDK system target before running. The returned raw per-PE replies contain the unique transaction tag, 48-bit timestamps, original IDs and all logits. Replay checks those words, the active edge cycle counters, all classes against FP64, the original-input GPU predictions, repeated outputs, and the matching native and Tungsten SDK values. It also independently reconstructs each upload from the graph. All twelve frames and normal shutdown are required.

The frozen native calibrations include six row-broadcast frames and two replicated-unicast frames per dataset. The local 762 × 1172 compile inventory is in each case's `local-target.json`. Actual system evidence uses the returned appliance compile for that dataset.

The interleaved worker also completed twelve tagged native SDK transfers on a four-original-destination, two-PE products control with 47 classes.
