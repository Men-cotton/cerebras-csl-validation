# Physical products GraphSAGE wire-budget comparison

Six transactions alternate contiguous and wire-budget ownership on the same native CSL image. Both policies cover the same original 128 destinations, incoming CSR edges and frozen trained weights on a 4×4 array of 16 compute PEs. Each frame uses the complete rectangular transfer. It returns the original logits, per-PE active counters, the enclosing device clock, source and total input words, and the host interval.

The host first checks all six stopped SDK transactions against the same original-ID scores previously returned by an independent CS-3 run. It records the 762×1172 native compiler preflight. The run retrieves the actual system compiler archive, validates its source and flags, checks the full PE and memcpy inventory, stages the measured worker and verifies every returned physical frame. The resource declaration and two steps allow the system runtime to supply its own compiler output.
