# Source-table broadcasts in a trained products hidden layer

One loaded native program processes dense edge features and a broadcast table of up to 32 frequently reused original source vertices. The 32 compute PEs, original destination assignment, per-row edge order, accumulator, projection and trained weights are fixed. Each measurement uses A, half-A and A in paired modes. Half-A scales the captured projections at the input to this hidden aggregation. Every returned FP32 hidden word is checked against the paired mode, an FP64 calculation and the original 40-window native SDK inference at A.

The reduced calibration picks two complete original rows on different owners, using the maximum overlap fraction among rows with 8–50 neighbors. Its 49 ordered edges include 24 shared sources. The complete comparison covers 203 hidden rows and 41,102 edges when its separately frozen request is available. The two cases share all device source and the upstream inference used to regenerate their inputs. Their release files name every executable host module and data file.

The system compiler is invoked for a 762 × 1172 fabric. The launcher binds its compiler archive, generated source and exact compiler arguments. Inside the job, the bootstrap verifies the application, RPC and both east/west memcpy firmware inventories before starting the measured worker. The results include all per-PE clock limbs, original IDs, selected dictionary slots, hit counts, actual transfer calls and lengths, returned tensors and hashes. The six-frame replay checks the system identity and the worker's normal stop.
