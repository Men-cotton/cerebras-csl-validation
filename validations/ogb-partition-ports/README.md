# Four-port GraphSAGE row assignments

Sixteen compute PEs process the same 128 trained products destinations. A single compiled image supports contiguous rows, edge-balanced rows and rows chosen to shorten the busiest source dictionary. Each hardware step runs twelve interleaved serial/concurrent transfers at two input scales, including restored input and empty fences on one PE. Every original class output must agree bit for bit with the common one-port reference and the matching SDK capture. The release pins all fixtures, images, decoded load ranges, SDK frames and host programs.
