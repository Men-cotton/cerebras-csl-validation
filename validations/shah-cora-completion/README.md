# Whole-Cora Shah completion observer

The host measures from entry to `launch("f_run", nonblock=False)` through return of a blocking read of one fresh 32-bit completion epoch from every application PE. Each PE publishes the epoch after its terminal row and column collectives, output writes and final local timestamp. The 17 × 64 rectangle contains 1,088 PEs, so completion transfers 4,352 bytes per call. Graph, input and weights are uploaded once per runtime. Every call uses the original trained Cora input. Numerics, input readbacks, role counters and 48-bit clocks are checked outside the host interval.

As in E233 compact CSR, each profile has two fresh runtimes. Each executes one warmup and five measured invocations. The primary profile keeps only outer PE clocks. The second profile adds four interior checkpoints to split the same critical PE's time across input projection, first aggregation with fences, ReLU/second projection, redistribution and second aggregation with fences. The host window includes launch and control read costs. PE clocks measure local intervals.

In the Tungsten research checkout, run `python3 experiments/cs3-validation/shah-completion/export.py --output /tmp/fresh-shah-observer` to build the watcher family and both requests. The source patch applies to the verified resident Shah family in the sibling cerebras-csl-validation checkout. Frozen compressed inputs contain the original corpus and checkpoint. The separate audit reconstructs the graph, packed input, FP64 model results, all-PE epochs and timing records for all six invocations from the returned capture.

For local SDK replay, compile the exported family’s `layout.csl` with the parameters of `tiny-r2-p0` or `tiny-r2-p1` in its `cases.json`. Both use a 24 × 6 fabric, offset (4,1), WSE-3, memcpy, one channel and maximum parallelism one. Run `local_sim.py --family FAMILY --case LABEL --build COMPILED --output FRESH_DIRECTORY` through `cs_python`. The local check verifies the generated geometry, profile, ELF footprint and six complete model calls.
